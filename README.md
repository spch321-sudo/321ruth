## xz1103（2026-11-03）小智最新功能：回答長度五段、讀者資料、滿版小智頁
- 從《321互動聖經》v2.57.2 的小智複製：**回答長度五段**（極短 100 字內／短 200～300／中 500～600（預設）／長 1000～1200／極長 2000～3000；舊的三段設定自動轉入：簡要→短、詳細→長）、**讀者資料**（暱稱、性別、年齡、身分、就職、在學、信仰、宗教背景、最想得到幫助的事；多份資料、12 歲以下只送暱稱）、**慕道友信仰背景**六種、每個對象 20 題範例問題。

## au1103（2026-11-03）空閒自動套用新版
- 新版到了時，若沒有在朗讀／播放、美圖工作室沒開、輸入框沒有未存的字、小智沒在回答、不在共讀中，就自動換成新版並重整；忙碌時只在頂端顯示「有新版本了」條，忙碌結束後自動套用，也可以隨時點更新條立即換。

- 做法：頁面尾端新增 `<script id="AU">` 掛件，不改既有程式。SW 版本 `路得記-ba4f076c592c-co1-gp1103-au1103`。
